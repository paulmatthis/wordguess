# Word Guess

A simple word-guessing game for the phone. Guess the hidden word in six tries;
letters turn green (right place), orange (wrong place) or black (not in the word).

- Word lengths 3 to 7, or random
- Optional starting word that is guessed for you at the start of every game
- Statistics per word length
- Works offline once installed

## Install on Android

1. Open the game's GitHub Pages address in Chrome.
2. Tap the menu (three dots), then **Add to Home screen** / **Install app**.
3. Open it from the home screen. After the first load it needs no connection.

## Where the idea came from

The style of play and the plain layout follow
[WordGuessr by Engaging Data](https://engaging-data.com/wordguessr-wordle/),
itself based on Josh Wardle's Wordle. The code here was written from scratch;
none of that site's code or word lists are used.

## Word list sources

No word in the game was written by hand. Everything is generated by
`tools/build.py` from the files in `tools/sources/`.

| Length | Answers | Accepted guesses |
|---|---|---|
| 5 | Wordle answer list (2,315 words) | Wordle answer list + Wordle allowed-guess list (12,972 words) |
| 3, 4, 6, 7 | SCOWL sizes 10–35, American spelling | ENABLE + SCOWL sizes 10–70 (American, British and Canadian spellings) |

- **Wordle lists** (`tools/sources/wordle/`): the lists from the original Wordle
  game by Josh Wardle, as it was before the New York Times edited them.
  Downloaded from the copies published by cfreshman:
  [answers](https://gist.github.com/cfreshman/a03ef2cba789d8cf00c08f767e0fad7b) and
  [allowed guesses](https://gist.github.com/cfreshman/cdcdf777450c5b5301e439061d29694c).
  Wordle is now owned by The New York Times Company; these lists are not mine
  and are included for personal use.
- **SCOWL** (`tools/sources/scowl/`): Spell Checker Oriented Word Lists,
  version 2020.12.07, by Kevin Atkinson, from <http://wordlist.aspell.net/>.
  Its copyright and permission notice is in `tools/sources/scowl/Copyright`.
- **ENABLE** (`tools/sources/enable1.txt`): the public-domain Enhanced North
  American Benchmark Lexicon by Alan Beale and others, downloaded from
  <https://github.com/dolph/dictionary>.

For lengths other than 5, only all-lowercase entries are used, which leaves out
proper nouns and abbreviations. The lists are otherwise used as published, so
plurals, past tenses and the occasional crude word can come up.

## Changing it

The game is plain HTML, CSS and JavaScript in `docs/` with no build step:

- `docs/index.html`, `docs/styles.css`, `docs/app.js`: the game
- `docs/sw.js`: offline support. Change the `CACHE` name when you change files,
  so installed copies pick up the new version.
- `python3 tools/build.py`: regenerates `docs/words.js` and `docs/dict/`
  from the source lists
